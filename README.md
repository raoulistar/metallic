# Metallic

## Overview
This is a personal project which was made for fun. I'm using this to experiment with animations, object oriented programming (OOP), stealth mechanics (like in the Metal Gear Solid franchise, though much simpler), and game mechanics.

## Built With
- Python 3
- Pygame-ce
(These are also the requirements to run this project)

## Installation
1. Clone this repo
```bash
git clone https://github.com/raoulistar/metallic
```
2. Install dependencies (if needed)

Install python from [python.org](url)

Windows pygame-ce installation
```bash
py -m pip install pygame-ce
```
3. Run the project
```bash
cd metallic
py main.py
```
